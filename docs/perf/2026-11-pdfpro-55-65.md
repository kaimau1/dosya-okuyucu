## PDFPRO_PERF — §6 zaman damgası logu (2026-11-13)

Yalnız debug/profil derlemesinde (`kReleaseMode` → yayında kod yok; nightly'de çıkmaz, `.r8test`
profil APK'sı kullan). Satır biçimi, kişisel içerik yok (yalnız faz adı + süre):

```
PDFPRO_PERF faz=<ad> ms=<n>
```

| faz | ölçülen aralık | kaynak |
|---|---|---|
| `kipe_gecis` | düzenleme denetleyicisi kurulduğundan ilk sayfanın blokları okunana dek (oturumda bir kez) | `PdfProEditController._load` |
| `uygula` | komut: sayfa yedeği + köprü işlemi (belge güncellendi; çizim hariç) — yazma bitişi hariç tüm komutlar ve kurtarma oynatması | `PdfEditSession.run` |
| `geri_al` / `yinele` | yedekten sayfayı geri koyma | `PdfEditSession.undo/redo` |
| `kaydet` | artımlı/yeniden yazımlı kaydın tamamı (sürüm geçmişi dahil) | `PdfProEditController.save` |
| `tus` | yerinde yazmada bir ara dizgi (tuş → belge güncellendi; ardışık tuşlar tek dizgide birleşebilir) | `PdfProEditController._runLive` |

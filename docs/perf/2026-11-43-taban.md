## Yeniden üretme
```bash
DOSYA_R8TEST=1 bash ci/prepare_android.sh   # android/ yoksa; varsa önce rm -rf android
flutter build apk --profile --target-platform android-arm64 && adb install -r build/app/outputs/flutter-apk/app-profile.apk
adb shell appops set com.dosyaokuyucu.dosya_okuyucu.r8test MANAGE_EXTERNAL_STORAGE allow
bash tool/pdf_profil.sh /sdcard/DosyaOkuyucuOlcum/<pdf> "PDF-B" com.dosyaokuyucu.dosya_okuyucu.r8test
OLCUM_VERISI=/sdcard/DosyaOkuyucuOlcum bash tool/perf_senaryo.sh MatePad
```
